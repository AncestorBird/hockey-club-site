# 富山大学アイスホッケー部 — BEYOND THE ICE.

部の紹介、見学・体験案内、検索・カテゴリー分類のあるブログを備えた静的サイトです。外部フォント、DB、認証サービス、トラッキングは使用しません。

## 開発・確認

Python 3.10以上が必要です。サイトのビルドと基本テストに追加パッケージは不要です。

```bash
cd /workspace/hockey-club-site
python3 scripts/build.py
python3 -m unittest discover -s tests -v
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

サーバーは **`dist`だけ** を配信してください。リポジトリ全体をWeb公開すると、Gitメタデータや開発ファイルまで配信されるおそれがあります。HTMLをファイルとして直接開くのではなく、ビルド後のHTTPサーバーで確認します。

Codexの各クラウドタスクは既に隔離されています。既存のチェックアウトを使い、明示的な依頼がなければGit worktreeを新設しません。サーバーのプロセスは保存・復元後に再起動が必要です。

### 実ブラウザでの確認（任意の追加環境）

このクラウド環境にはPlaywrightとChromiumが導入済みです。

```bash
python3 scripts/check_browser.py
```

PC・スマホの表示、検索、カテゴリー、0件時のリセット、記事遷移、メニューのキーボード操作、JavaScript無効時の閲覧、公開対象外ファイルへのアクセスを確認します。現在の出力から実画面を撮影し、`artifacts/`へ保存します。ブラウザテスト用サーバーは終了時に停止します。

他の環境でこの追加チェックを使う場合は、隔離したPython環境にPlaywrightを導入し、システムChromiumまたはPlaywrightのChromiumを準備してください。通常の開発・ビルドには不要です。

## 記事を更新する

`posts.json`に記事を追加し、ビルドを再実行します。Web管理画面はありません。

```json
{
  "id": "2026-10-15-club-note",
  "title": "記事のタイトル",
  "author": "公開してよい著者名",
  "date": "2026-10-15",
  "category": "部員日記",
  "body": "<p>本文をここに書きます。</p>"
}
```

- `id`は半角英小文字・数字・ハイフンで一意にします。既存の記事URLを保つため、公開済みのIDを変更しないでください。
- 日付は`YYYY-MM-DD`です。日付が新しい記事から表示します。
- カテゴリーは記事データから自動生成されます。現在は「ホッケー入門」「お知らせ」「部員日記」です。
- 本文で使えるタグは`p, br, strong, em, h2, h3, ul, ol, li, blockquote, a`です。任意のスクリプト、イベント属性、画像の埋め込みなどは取り除きます。
- リンクは`https:`, `http:`, `mailto:`または`#`で始まる同一ページのアンカーに対応します。
- サンプル記事には`"sample": true`を付けます。記事に注意書きを表示し、トップの紹介・サイトマップから除外し、検索エンジンへ`noindex`を指定します。
- 旧ブログの記事ID・日付・本文は保持しています。旧`blog.html#記事ID`も一覧内の同じ記事カードへつながります。

## ファイル構成

| 場所               | 内容                                             |
| ------------------ | ------------------------------------------------ |
| `templates/`       | トップ、ブログ一覧、記事ページのHTMLテンプレート |
| `css/style.css`    | PC・スマホ共通のデザイン                         |
| `js/site.js`       | メニューとブログ検索の段階的拡張                 |
| `posts.json`       | ブログ記事の更新元                               |
| `contents/`        | 既存フライヤー、独自アイコン、共有画像           |
| `scripts/build.py` | 公開ファイルだけを`dist/`へ出力                  |
| `tests/`           | 生成物・リンク・HTML安全処理のテスト             |
| `dist/`            | 再生成できる公開用成果物。Git対象外              |
| `artifacts/`       | 開発環境の実画面。Git対象外                      |

連絡先は利用者の指定に基づき`toyama.univ.icehockey@gmail.com`です。Instagramの`@toyama_angels`は既存の新歓フライヤーから確認しました。メールリンクはメールアプリを開きます。サイトからの自動送信や受信確認機能はありません。

## 公開・復旧

今回の作業では本番公開を行いません。公開時の確認は[公開手順](docs/release.md)にまとめています。配信する成果物は`dist/`です。ソースのルートから配信する従来の設定はそのまま使えません。

変更を戻す場合は、変更前のソースをGitから別の安全な場所へ取り出してビルドし、その成果物を配信します。現在の作業を無断で`reset --hard`する必要はありません。DBや個人アカウントの移行はありません。
